# Townlight governance records

The [Townlight Beta 1 Agent Governance Record — DRAFT](townlight-beta-1-agent-governance-record-draft.md)
is the canonical shared-platform technical contribution for deploying-agency
review. It contains the AI-use inventory, all 47 framework fields, approval
boundaries, use addenda, commissioning worksheet and evidence limits.

The record distinguishes the published Beta 1 installer from the locally
corrected Records source candidate. A source correction does not update an
existing installation or inherit installed acceptance. See the record's candidate
section and [correction evidence](evidence/records-export-freshness-2026-11-02.json).

Townlight maintains the software facts and versioned evidence here. A deploying
agency selects its actual uses, supplies deployment facts and decisions, and
verifies and owns its final deployment record. No city has been commissioned by
this document. Its author review is not independent agency review or approval.

Organization-profile links and any future website presentation should point back
to this versioned record. Website publication is a separate authorized step.
Historical organization/process documents remain in the [governance index](index.md).
