# Townlight Windows 1.9.1.1 operator notes

These instructions cover the [published Windows 1.9.1.1 beta](https://github.com/townlight/townlight/releases/tag/townlight-windows-v1.9.1.1). See the [maintenance handoff](https://github.com/townlight/townlight/releases/download/townlight-windows-v1.9.1.1/HANDOFF-Windows-1.9.1.1.md) for the signed installer identity, verified workflows and evidence limits.

## Meeting and packet

Schedule a meeting and draft the agenda items using the existing forms. In Meetings, search for the saved meeting by title or select its date and title. Choose an unassigned item and select **Place on this agenda**. Select an item in **Packet order** and use **Move up** or **Move down** to order the agenda. Use **Save packet** to save a new version. **Deliver saved packet files** uses the latest saved version and writes local staff files in the Townlight profile. It does not post the packet online.

## Ordinance proposal and decision

Under Code & Ordinances, open **Ordinance proposals and meeting decisions**. Select the current code section and saved meeting, enter the proposal and send it. Use **Open this proposal in Meetings** to view the selected meeting. Choose the saved proposal and record the human decision. Use **Open this proposal in Code** after an adoption. Review the recorded decision, choose the registered codification source, verify the effective date and select **Record codification closeout**. Staff must explicitly choose whether the version becomes current.

## Record the meeting

Select the saved meeting and choose **Open Station**. Confirm the meeting shown in Station. For a local camera and microphone, save the selected inputs, then run **Record 10-second input test**. Station waits for capture to start before timing the clip, so the test can take longer on the first run. Play the preview and confirm the picture and sound before starting the meeting recording. If the operator browser closes, reopen Station and locate the recording by title before stopping it. Station uses the configured recording bitrate. Check storage readiness before a long meeting and choose the intended audio and video inputs before starting. This uses the bundled Station recorder in the normal Townlight profile. It does not set up CivicCast.

If the Records service requires preparation, an administrator selects **Prepare Records** in Townlight and confirms. The preparation uses the existing backup-and-verify process. Once a recording is complete, send it to the selected Records request as a private document. Review the request and its attached recording in Records. Publication and disclosure remain staff decisions.
