How they work together

A handoff carries context.

Meetings provides adoption evidence to Code. Code supports cited Zoning, Permitting and Inspections work. Planning relates policy to Meetings/Zoning evidence. Reviewed public copies reach Records by explicit selection.

Sharing a document is not automatic publication, a permit approval or an enforcement action. Notice and Access support the composition without expanding this eight-product set.
