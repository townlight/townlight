Windows 1.9.2.1 signed release

Windows 1.9.2.1 is a historical public beta. Download the signed MSI from the release catalog; verify its checksums and read the acceptance summary. Acceptance used synthetic data on a physical Windows host and clean Sandbox guest on the same machine; direct upgrades, two physical PCs and a live city environment were not tested.

Technical sources are pinned to canonical commit 1bc45be5a14aa969e53b87b1cef1f278dadc79a4: shared staff guide, native client, staff gateway, packet contract and portal contract. Versioned API snapshots and previous source-pin files keep their historical identities.

Windows 1.8.1.1 adds shared meeting imports for 31 source families, with 34 supported source/format pairs. Installed Windows Sandbox checks exercised preview, save and durable readback using public captures and fixtures, plus the documented Townlight handoffs. These checks do not establish automatic discovery on every live portal or a complete retest of every module. Acceptance and limits.
