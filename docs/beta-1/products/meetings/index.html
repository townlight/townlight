Inside the workflow

What Meetings supports

Prepare for the dais

Assemble packet documents, create notice workpapers and retain posting proof.

Record what happened

Keep motion and vote corrections, action items, and adopted minutes with the meeting.

Carry decisions forward

Link a Code proposal to its adopted decision or pass meeting context to Station, which you can set up during Townlight first run.

Evaluate locally
