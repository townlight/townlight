Install this beta on a fresh profile

  1. Download Townlight-Windows-x64-1.7.1.1.msi and the published checksums from this exact release.
  2. In PowerShell, run Get-FileHash .\Townlight-Windows-x64-1.7.1.1.msi -Algorithm SHA256. The MSI SHA-256 must be 7553bb3ca457360a99878953f86d54211d77a250129a6744d9d637a2fb4be9e3.
  3. Check the installer signature with Get-AuthenticodeSignature .\Townlight-Windows-x64-1.7.1.1.msi. It must report Valid; confirm the signer matches the publisher named on the release page before installing.
  4. Follow the first-run guide and evaluate with synthetic data first.

This MSI does not upgrade an existing legacy profile. Preserve existing data and backups; follow the manual's recovery guidance. Use the explicit download above: GitHub's Latest download now resolves to this public beta.
