Install this beta on a fresh profile

  1. Download Townlight-Candidate-Windows-x64.msi and the published checksums from this exact release.
  2. In PowerShell, run Get-FileHash .\Townlight-Candidate-Windows-x64.msi -Algorithm SHA256. The MSI SHA-256 must be 8cebaea95fa62f582326a1a0c1af3cb54233c40dbb41d88324170eb1b3f25ade.
  3. Check the installer signature with Get-AuthenticodeSignature .\Townlight-Candidate-Windows-x64.msi. It must report Valid; confirm the signer matches the publisher named on the release page before installing.
  4. Follow the first-run guide and evaluate with synthetic data first.

This MSI does not upgrade an existing legacy profile. Preserve existing data and backups; follow the manual's recovery guidance. Use the explicit download above: GitHub's generic Latest shortcut currently points to an older release.
