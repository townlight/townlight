Historical Windows 1.9.1.1 installation and upgrade notes

  1. Download Townlight-Windows-x64-1.9.1.1.msi and the published checksums from this exact release.
  2. In PowerShell, run Get-FileHash .\Townlight-Windows-x64-1.9.1.1.msi -Algorithm SHA256. The MSI SHA-256 must be ef86e746b02970767ec4aa72c0dbb966e1225689a4b24ffdb72484760cb86662.
  3. Check the installer signature with Get-AuthenticodeSignature .\Townlight-Windows-x64-1.9.1.1.msi. It must report Valid; confirm the signer matches the publisher named on the release page before installing.

Fresh installation. For a fresh installation, run the signed Windows 1.9.1.1 MSI, then follow first-run setup with an empty database and a new Townlight profile. Follow the first-run guide and evaluate with synthetic data first.

Upgrade from Windows 1.9.0.1. Back up your city data and settings in Townlight and close the app before running the signed MSI. Reopen Townlight under the same Windows account with your existing profile. If Station shows as unconfigured, open Settings → Modules → Townlight Station and select Set up meeting recording. After restoring a backup, start the services before checking your records. The acceptance summary identifies the 1.9.0.1 upgrade run on the earlier signed candidate. The separate verified 1.8.2.1 upgrade ended at 1.9.0.1. A direct upgrade from 1.8.2.1 or older to 1.9.1.1 has no test result.
