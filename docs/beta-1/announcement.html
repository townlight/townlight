Townlight Windows public beta 1.8.1.1 is available

Municipal software cities can actually own.

Townlight's signed Windows x64 public beta is available now. It brings municipal work into connected local workspaces, with a record of the sources, staff review and decisions behind it. The installer was published on 11 November 2026; this announcement covers the exact signed Windows 1.8.1.1 candidate.

What you can evaluate

  • Records: public-records request, review and export workflows.
  • Meetings: meeting and agenda preparation, packets, motions and votes, minutes, archives and proceedings readback.
  • Code: proposal and adoption work connected to Meetings.
  • Access: saved accessibility reviews, local-model rewrite and Spanish translation drafts, retained provenance and Records exports for human review.
  • Notice: content-bound review and approval, posting proof, verified archives and Records readback.
  • Zoning, Planning, Permitting and Inspections: staff workspaces whose exercised paths and limits are described in the manuals and acceptance.

Install or upgrade this beta

  1. Download Townlight-Windows-x64-1.8.1.1.msi and the published checksums from this exact release.
  2. In PowerShell, run Get-FileHash .\Townlight-Windows-x64-1.8.1.1.msi -Algorithm SHA256. The MSI SHA-256 must be 9e9363ec5119a2ee4c0d69b4dd40b21a535571a11eb3750d57b8a24d4472a5da.
  3. Check the installer signature with Get-AuthenticodeSignature .\Townlight-Windows-x64-1.8.1.1.msi. It must report Valid; confirm the signer matches the publisher named on the release page before installing.

Fresh installation. For a fresh installation, run the signed Windows 1.8.1.1 MSI, then follow first-run setup with an empty database and a new Townlight profile. Follow the first-run guide and evaluate with synthetic data first.

Windows 1.8.1.1 has fresh-install acceptance. An in-place upgrade to 1.8.1.1 was not exercised. The previous Windows 1.8.0.1 release tested upgrade from 1.7.2.1; that result applies to 1.8.0.1. Before an existing-city evaluation, back up city data and settings, close Townlight, keep the existing %LOCALAPPDATA%\CivicSuite profile, and use the same Windows account. Keep the prior installer and a restore path. Station continues to use its separately configured service.

Portal and branding

The resident portal is a separately deployed beta with its own release and deployment guide. Installing this Windows MSI does not deploy a public website.

The website and documentation now use the selected Open Hall identity. Application and installer icons will adopt it in the next software update. This release includes a rebuilt Windows desktop and updated local runtime. The previous Windows release and its evidence remain intact.
